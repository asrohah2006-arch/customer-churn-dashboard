**Customer Churn Prediction Using Machine Learning and Deep Learning**  
Python, pandas, scikit-learn, TensorFlow/Keras, Streamlit

- Built an end-to-end telecom churn pipeline covering data cleaning, exploratory analysis, categorical encoding and feature scaling.
- Trained and compared Logistic Regression, Random Forest and a Keras neural network on the same stratified holdout set using precision, recall, F1 and ROC-AUC.
- Added model explainability with SHAP when available and bounded permutation importance as a fallback, then created a Streamlit dashboard for model comparison and single-customer risk demos.
